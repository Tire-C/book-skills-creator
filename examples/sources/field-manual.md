# Lantern Field Desk Manual

This original training manual describes a fictional team that handles incoming field reports. It is a synthetic fixture, not operational advice.

## Terms and background

A signal is a report that might require attention. A case is a signal with an owner and a recorded decision. A watch note is an observation kept for later review. These definitions help readers understand the workflow but are not procedures by themselves.

## Intake a signal

When a new report arrives, record the time, location, reporter, claimed effect, and any missing details. Assign a case ID. Ask one focused question for each missing fact that changes the decision. Keep the original report separate from later interpretation. The output is a concise intake record.

## Decide the route

Use the intake record to choose one of three paths. If an active safety effect is reported, escalate to the duty lead. If the effect is uncertain but repeatable, open a watch note and set a review time. If it is clearly a duplicate, link it to the existing case and explain the match. Do not infer certainty from an urgent tone alone. Record the evidence and the reason for the chosen path.

## Verify and close

For an escalated case, ask the owner to confirm the current condition and the action taken. Check the decision against the intake record. Record any exception. In the base manual, verification is due within two hours of escalation. Close only when the owner confirms the result or explicitly records why verification could not be completed.

## Full response workflow

A full response starts with intake, continues through routing, and ends with verification when escalation occurs. Pass the case ID and the minimum facts between steps. A watch note stays open for its scheduled review; a duplicate does not run verification again.

## Quick triage wording

Some staff call the first two actions “quick triage.” This is a shorthand for intake plus routing and should not become a separate capability with copied instructions.

## Checklist and anti-pattern

Before handing off an escalated case, check that it has an owner, case ID, reason, and next review time. Avoid treating a dramatic description as proof of an active effect. The checklist belongs with the workflow and the anti-pattern supports the routing skill.

## Ambiguous request

“Handle this” lacks the report, desired outcome, and time context. Ask which signal is meant and whether the user needs intake, a routing decision, or the full response.
