# Decide the route

## Mission

Choose and justify one route for a recorded signal.

## Use when

An intake record is ready for a routing decision.

## Inputs

- Intake record
- Known case matches

## Procedure

1. Check for a reported active safety effect; escalate if present.
2. If uncertain but repeatable, open a watch note with a review time.
3. If clearly duplicated, link the existing case and explain the match.
4. Record the evidence and reason for the choice.

## Output

A route decision with its reason and next action.

## Constraints

- Urgent wording alone does not establish an active effect.
